## Overview

Tic Tac Toe is an interactive browser game built with HTML, CSS, and vanilla JavaScript. It supports local two-player matches and single-player games against a computer opponent. The application manages turns, validates moves, detects wins and draws, and tracks match statistics.

## Features

- **Two game modes:** Play against another person or the computer.
- **Win and draw detection:** Evaluates rows, columns, and diagonals after each move.
- **Scoreboard:** Tracks wins, draws, and total games.
- **Persistent statistics:** Saves the selected mode and scores in browser local storage.
- **Game controls:** Start a new game, restart a match, switch modes, and reset scores.
- **Responsive interface:** Play across desktop and mobile screen sizes.

## How to Play

1. Select Two Player or Computer mode.
2. Choose an available cell to place your mark.
3. The game validates the move and updates the board.
4. In computer mode, the opponent makes its move automatically.
5. The game checks for a win or draw and updates the scoreboard.

## Run Locally

```bash
git clone https://github.com/mdnav/tic-tac-toe-game.git
cd tic-tac-toe-game
```

Open `index.html` in a modern browser. No package installation or build step is required.
